Task 04: The Pirate King's Challenge

1)The 67th OEIS problem

This is a really easy one to start with. We just have to make sure the adjecent numbers in the series should not share the same GCD. For this I took series of the odd number multipling to the previous one. For eg, 1,3(1*3),15(3*5),35(5*7).....so on. This makes sure everytime the GCD of the adjacent two number is a unique odd Number. It ain't possible with even numbers because they have a common divider : 2.
